    How it works

    Snapshots instead of gut feeling

    A script regularly queries Spansh's station search, stores the current Tritium market of every station around Colonia and adds new market updates to the history. GitHub Actions then rebuilds this page.

    • Data comes from player uploads (EDDN) – Market update shows how old an entry really is.
    • Fleet carriers jump – their system can change between two snapshots.
    • Filters are stored in the URL – views can be shared as a link.
