    Wie das funktioniert

    Snapshots statt Bauchgefühl

    Ein Script fragt in festen Abständen die Stationssuche von Spansh ab, speichert den aktuellen Tritium-Markt aller Stationen im Umkreis von Colonia und hängt ihn an den Verlauf an. GitHub Actions baut daraus diese Seite neu.

    • Daten stammen von Spieler-Uploads (EDDN) – Market-Update zeigt, wie alt ein Eintrag wirklich ist.
    • Fleet Carrier springen – ihr System kann sich zwischen zwei Snapshots ändern.
    • Filter landen in der URL – Ansichten lassen sich als Link teilen.
    Daten: Spansh / EDDN · Stand – Fan-Projekt, nicht mit Frontier Developments verbunden. Elite Dangerous ist eine Marke von Frontier.
